## ❓ FAQ

**Q: Will it take long to build?**
A: First time ~2-3 minutes (downloads Maven). Next times ~30 seconds.

**Q: What if Maven is already downloaded?**
A: Just runs immediately. build.bat checks if it exists first.

**Q: Can I use IntelliJ to run it?**
A: Yes! Right-click ExamInvigilatorApplication.java → Run

**Q: How do I stop it?**
A: Press Ctrl+C in the command prompt

**Q: Can I change the port?**
A: Yes, edit `application.properties`: `server.port=8081`

**Q: What if port 8080 is in use?**
A: Kill Java: `taskkill /IM java.exe /F` or change port

## 📞 Support

If something goes wrong:

1. **Build fails?** 
   - Run: `mvn clean`
   - Then: `build.bat`

2. **Database error?**
   - Delete: `examdb.db`
   - Then: `build.bat`

3. **Port conflict?**
   - Kill Java: `taskkill /IM java.exe /F`
   - Or change port in application.properties

4. **JWT errors?**
   - Make sure to include "Bearer " before token
